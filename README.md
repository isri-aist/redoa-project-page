# ReDOA Project Page

Static project page for “ReDOA: Real-World Distillation via Observation Alignment for Image-Based Manipulation Policy Learning.”

Open `index.html` in a browser or serve this directory with any static web server. The page and all media assets are self-contained in this repository; the stylesheet's optional Google Fonts import falls back to local sans-serif fonts when offline.

The PDF, figures, and demonstration video are in `assets/`. Named marker-removal and rollout-evaluation videos are in `assets/videos/`; see its README for the clip list and source descriptions.
